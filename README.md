# Projekt-ML

Projekt realizowany w ramach przedmiotu "Metody AI w badaniu zagrożeń w systemach komputerowych", rok akademicki 2025/2026.


## Zbiór danych
Dane wykorzystane w projekcie pochodzą z serwisu Kaggle: 
[Air Quality and Pollution Assessment](https://www.kaggle.com/datasets/mujtabamatin/air-quality-and-pollution-assessment)

*   **Zmienna docelowa (Target):** `Air Quality` (klasy: Good, Moderate, Poor, Hazardous)
*   **Główne cechy (Features):** m.in. Temperatura, Wilgotność
*   **Rozmiar zbioru:** 5000 wierszy, 10 kolumn.
